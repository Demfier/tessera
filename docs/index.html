Tessera Star on GitHub

Window snapping, Space switching, and display moves for macOS

Tessera is a free, open-source menu-bar app. Use keyboard shortcuts to snap windows, switch Spaces without the slide animation, and move windows between displays, including full-screen windows. It replaces Rectangle, InstantSpaceSwitcher, and the window moving in Second Display Pro.

Download for Mac
curl -fsSL https://demfier.github.io/tessera/install.sh | bash

Requires macOS 14 or later, on Apple silicon or Intel. See the release notes. The install command downloads the latest release, checks its signature, and installs it to Applications. You can read the script before running it.

Try the shortcuts

Click a shortcut, or press it on your keyboard.

Features

Snapping windows

Snap the focused window to halves, corners, thirds, fourths, or sixths, or maximize, center, resize, or restore it. Pressing a half shortcut again moves the window to the next display. The layouts and default shortcuts are the same as Rectangle's.

Switching Spaces

Switch to the Space on the left or right, jump to Space 1–10, or go back to the last Space, without the slide animation. Three-finger trackpad swipes can skip the animation too. This uses the engine from InstantSpaceSwitcher.

Moving between displays

Move a window to the display on the left, right, above, or below. A full-screen window leaves full screen, moves, and goes back into full screen, which takes about two seconds. You can also move keyboard focus to another display. Windows move back to a display when it reconnects.

Default shortcuts

You can change any of them in Settings. Fourths, sixths, next and previous display, and a few other actions have no default shortcut.

Install

The install command at the top of the page does steps 1 and 2 for you. To install manually:

  1. Download Tessera

    Download Tessera.zip, unzip it, and move Tessera.app to your Applications folder.

  2. Allow it to open

    Tessera isn't notarized by Apple, because notarization requires a paid Apple Developer account. As a result, macOS blocks it the first time you open it. Click Done, open System Settings › Privacy & Security, scroll to the message about Tessera, and click Open Anyway. You only need to do this once.

  3. Turn on Accessibility access

    Tessera needs Accessibility access to move other apps' windows and to switch Spaces. When it asks, turn Tessera on in System Settings › Privacy & Security › Accessibility. Updates keep this setting.

Tessera runs in the menu bar and starts at login. If Rectangle or InstantSpaceSwitcher is running, quit it, since it uses the same shortcuts.

Build from source

Requires Xcode with Swift 6, on macOS 14 or later.

git clone https://github.com/Demfier/tessera.git
cd tessera
scripts/build.sh --install

Tessera is open source under the MIT license. Space switching uses the engine from InstantSpaceSwitcher by jurplel. Layouts and default shortcuts follow Rectangle.

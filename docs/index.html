Tessera Source on GitHub

Every window, every display, every Space. From the keyboard.

Tessera is a free menu-bar app for macOS. It snaps windows into place, switches Spaces without the sliding animation, and carries full-screen apps from one display to another. One small app instead of three.

Download for Mac
curl -fsSL https://demfier.github.io/tessera/install.sh | bash

Version 1.0 for macOS 14 or later, Apple silicon and Intel. The install command skips macOS's first-launch warning; read the script before running it.

Try the shortcuts

Press a shortcut, or click one above.

One app instead of three

Instead of Rectangle

Halves, corners, thirds, fourths and sixths, maximize, center, grow and shrink, and restore. Press a half again and the window walks onto the next display.

Instead of InstantSpaceSwitcher

Switch Spaces with no slide, so the pointer is usable the moment you let go. Jump straight to Space 1 to 10, or back to the last one. Three-finger swipes can be instant too.

Instead of Second Display Pro

Send a window to the display on that side, even a full-screen one: Tessera leaves full screen, moves it, and goes full screen again. Windows go back where they were when a display reconnects.

Default shortcuts

Change any of them in Settings, where more actions (fourths, sixths, next display and others) wait to be bound.

Installing

The install command above does steps 1 and 2 for you. To install by hand:

  1. Download and move it to Applications

    Download Tessera.zip, open it, and drag Tessera into your Applications folder.

  2. Open it once from System Settings

    Tessera isn't notarized by Apple (that takes a paid developer account), so the first time you open it macOS says it can't check it. Click Done, then go to System Settings › Privacy & Security, scroll down to “Tessera was blocked”, and click Open Anyway. macOS only asks once.

  3. Allow Accessibility access

    Tessera opens its settings and asks for Accessibility access, which is what lets it move other apps' windows. Turn Tessera on in System Settings › Privacy & Security › Accessibility. Updates keep this permission.

Tessera lives in the menu bar and starts at login. If you use Rectangle or InstantSpaceSwitcher, quit them so the shortcuts don't collide.

Building it yourself

You need Xcode and macOS 14 or later.

git clone https://github.com/Demfier/tessera.git
cd tessera
scripts/build.sh --install

Tessera is free and open source under the MIT license. Instant Space switching uses the engine from InstantSpaceSwitcher by jurplel. Layouts and default shortcuts follow Rectangle.
